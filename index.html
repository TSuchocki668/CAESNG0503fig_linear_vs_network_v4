Chain of dependency: each part relies on exactly one other, so a single loss breaks every link that follows it.
Redundancy: multiple parts perform the same function, so a loss in one is absorbed by the others.

A grasshopper decline collapses the grassland chain above it but barely registers in the grassland web, where beetles and moths keep the frog fed. A parasitoid wasp with only one caterpillar host has no fallback if that host declines. In the 1840s, Ireland's near-total reliance on a single potato variety meant that one strain of blight could destroy the harvest nationwide, contributing to a famine that killed roughly a million people. A food forest growing potatoes alongside corn, squash, beans, blueberry bushes, and fruit trees, like the system beside it, loses the potato crop to blight and still brings in a harvest.
